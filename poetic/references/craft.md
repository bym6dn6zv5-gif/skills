# 诗性与情致

## 把诗性落在每一句的作用上

一句可以起境、照应、转情、设问或回响。优先写出这些作用，再推敲字词、声息和停顿。提高诗性时，既可凝缩，也可适度铺陈；选择能让情意更鲜明的方式。

回看整段：景物之间是否互相牵引，语气是否随情绪流动，末句是否为前句添了余味？只做必要的一次调整，不把创作变成逐项审查。

## 接情，也接境

听见用户句子里的盼望、迟疑、欣喜或眷恋，让回应与它发生关系。可以借一个动作、一处景象、一层时空变化相和，也可以直抒情意。

纯写景时写出景的气韵；有人的情意时，让景物回应那份情意。无需为增加温度而补上口头安慰，也无需为了显得客观而将感情全部撤去。

## 形成有联系的变化

- 从眼前转向远处，让距离承担意味。
- 从此刻照见往昔，让时间形成回声。
- 让事物的动静、明暗、聚散互相衬映。
- 让一处细节承接抽象情意，或让一句直抒照亮前面的景。
- 按需要采用复沓、对偶、递进或反问，让情绪回旋。

每次选择贴合当前句意的变化；不要固定成相同的三段结构。

## 调节古意与浓度

| 气息 | 可用做法 |
| --- | --- |
| 清丽 | 凝练用字，以光色与轻盈动作传情，保留明净声息 |
| 婉转 | 延迟说尽，让一景牵出一情，句间有所回环 |
| 情深 | 允许直接抒情，以具体的指向与选择托住分量 |
| 旷达 | 使视野舒展，以景与时间打开胸襟，避免空泛口号 |
| 疏淡 | 减少修辞数量，留下仍有意味的照应与停顿 |
| 浓郁 | 丰富虚实、远近与感官层次，使意象围绕同一情致展开 |

古意可以来自词义、语序、句式与声韵。使用典雅语汇时保持语义通顺，不以生僻字、伪典故和强行押韵充数。用户没有要求严格格律时，不让格律核对妨碍自然创作。

## 避免几种失色

- **景物空转**：添了许多景物，仍未回应原句的意味。回到用户真正说出的那一点。
- **口语泄气**：成句之后接上泛泛安慰、生活建议或邀约。让作品停在情境之内。
- **华词堆积**：修辞彼此争夺、意象互不相关。保留有内在联系的部分。
- **情意泛化**：任何话题都写成相思、遗憾或人生道理。重新判断此刻的情致。
- **刻意冷淡**：为追求留白而删去所有情感。恢复一句有分量的相和。

## 改稿时保留灵气

优先保留用户喜欢的意象、节奏和有力量的句子。修改能解释的败笔，保留有效的陌生感；不要把所有跳跃和含蓄都磨平。
