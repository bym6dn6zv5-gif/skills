# 诗意的语言操作

## 从感受到具体语言

先找一个能承载当前感受的细节，再决定如何写。可以从形、声、触感、温度、气味、空间与时间中选择，不必堆齐感官。

例如，想写雨后迟迟未散的心情，可以写“雨停了，伞沿还留着几滴水”；若本轮需要物的安静，就停在水滴，不一定加上拟人、人生比喻与道理。

## 调节浓淡

| 想要的质地 | 可做的修改 |
| --- | --- |
| 清淡、克制 | 减少形容词与判断，保留一个细节和一个动作 |
| 温暖、生活感 | 引入饭菜、灯、衣物等已有场景中的具体物件，让关切通过动作显现 |
| 明亮、灵动 | 使用轻快动词、短停顿与细小变化，允许一点玩心 |
| 疏远、空旷 | 借声音、远近、遮挡与间隔组织空间，不机械添加孤独与绝望 |
| 古雅、有韵 | 调整语序、用字与声息，少量凝练，保持可理解的现代语义 |
| 浓丽、丰盈 | 丰富感官层次，同时维持一个中心画面，删掉互相争夺的比喻 |

不要把“更有诗意”一律改成更长、更苦或更文言。用户说“淡些”时，首先删减，不添一段说明。

## 让比喻成立

先确认被比之物之间共享的形态、动作、关系或感受。检查比喻是否真正推进意思；只是显得华美时可以删掉。

一小段文字不必同时把心情写成海、鸟、火与雪。可以变化，但让变化具有可感的联系。

## 用声音与节奏组织意味

- 以自然朗读检查停顿，让重音落在有意义的词上。
- 短句可以凝聚，长句可以舒展；根据当前情绪选择，不固定成三句一组。
- 重复可以形成回声，也可以变成拖沓；只保留真正有变化或强调作用的重复。
- 用标点和句法制造节奏，避免以无意义的换行、破折号和省略号堆气氛。

## 给留白一个边界

省略可以让读者参与，但至少留下情景、动作、指向或关系中的一个可辨认支点。

不要在已经成立的末句后补“这就是人生”“愿你余生安好”等总括。用户要阐明意义时再解释，不让每一段诗意都自带注释。

## 校准反馈

用户喜欢一个词、一句或一种节奏时，提取它的有效特征继续，而非机械复制同一句式。用户否定时根据其指出的浓淡、画面、情感或语体直接改稿。

对于“还是不对”这样的反馈，可以给一个方向明确的修订；若仍缺关键尺度，再问一个会改变改法的问题。
